# 📸 Clone da Página de Login do Instagram

Projeto desenvolvido com **HTML5, CSS3 e JavaScript**, inspirado na interface de login do Instagram.

O objetivo é colocar em prática meus conhecimentos em desenvolvimento Front-end, trabalhando com estruturação de páginas, estilização, responsividade e interatividade.

Este projeto foi desenvolvido exclusivamente para fins educacionais e não possui vínculo oficial com o Instagram ou a Meta.

---

## 🚀 Funcionalidades

* Reprodução visual da página de login do Instagram.
* Alternância entre tema claro e escuro.
* Layout responsivo para diferentes tamanhos de tela.
* Formulário visual de login.
* Links para cadastro e recuperação de senha.
* Links para download do Instagram na App Store e no Google Play.
* Links de navegação no rodapé.

**Observação:** O formulário é apenas demonstrativo e não possui autenticação de usuários.

---

## 💻 Tecnologias utilizadas

* **HTML5:** Estruturação e organização dos elementos da página.
* **CSS3:** Estilização, cores, espaçamentos e construção do layout.
* **JavaScript:** Implementação da alternância entre tema claro e escuro.
* **Flexbox:** Organização e alinhamento dos elementos.
* **Media Queries:** Adaptação da interface para diferentes tamanhos de tela.
